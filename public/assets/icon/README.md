# Icon Assets

This folder contains icon images used for floating buttons in the learning pages.

## Required Icons:

1. **the-challenge-icon.png** - Icon for The Challenge floating button
   - Recommended size: 96x96px or larger
   - Format: PNG with transparent background
   - Suggested design: Target/bullseye icon or document with checkmark

2. **ai-icon.png** - Icon for AI helper floating button
   - Recommended size: 96x96px or larger
   - Format: PNG with transparent background
   - Suggested design: Robot/AI assistant icon or sparkle/magic wand

## Design Guidelines:

- Use simple, recognizable shapes
- Ensure good contrast on both light and dark backgrounds
- Keep design minimal and clean
- Icon should be recognizable even at small sizes (40x40px)

## Current Status:

If icons are missing, the buttons will use colored background with the icon image.
Please add the icon files with the exact names specified above.
