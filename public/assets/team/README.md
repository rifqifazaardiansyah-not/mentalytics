## 📐 Spesifikasi Teknis

### Format File:
- **Disarankan**: JPG/JPEG
- **Alasan**: 
  - Ukuran file lebih kecil (loading lebih cepat)
  - Kualitas sudah sangat baik untuk foto profil
  - Dukungan browser universal

### Ukuran Foto:
- **Dosen**: 800x800px (ditampilkan 192x192px di web)
- **Anggota Tim**: 600x600px (ditampilkan 128x128px di web)
- **Aspect Ratio**: 1:1 (square/persegi)

### Kualitas:
- **Resolution**: 72-150 DPI (untuk web)
- **Compression**: 80-90% (balance antara kualitas & ukuran)
- **Max File Size**: 500KB per foto (ideal: 100-300KB)

## 🎨 Tips Foto yang Baik:

1. **Pencahayaan**: 
   - Cahaya natural dari depan
   - Hindari backlight (cahaya dari belakang)

2. **Background**:
   - Netral (putih, abu-abu, atau blur)
   - Tidak ramai/mengganggu

3. **Framing**:
   - Head & shoulders (kepala dan bahu)
   - Centered (di tengah frame)
   - Eye-level atau sedikit dari atas

4. **Expression**:
   - Natural smile
   - Profesional namun approachable

5. **Dress Code**:
   - Formal atau semi-formal
   - Warna yang kontras dengan background

## 🔧 Tools untuk Edit Foto:

### Online (Gratis):
- **Remove.bg**: Hapus background otomatis
- **Canva**: Resize & crop ke 800x800px
- **Squoosh.app**: Compress JPG tanpa kehilangan kualitas

### Desktop:
- **GIMP** (gratis): Full-featured photo editor
- **Adobe Photoshop**: Professional editing
- **Windows Photos**: Simple crop & resize

## ✅ Checklist Sebelum Upload:

- [ ] Nama file sudah benar (sesuai list di atas)
- [ ] Format JPG/JPEG
- [ ] Ukuran 800x800px (dosen) atau 600x600px (tim)
- [ ] File size < 500KB
- [ ] Foto jelas dan tidak blur
- [ ] Background netral
- [ ] Wajah terlihat jelas

## 📝 Cara Upload:

1. Siapkan foto yang sudah diedit
2. Rename sesuai nama file yang ditentukan
3. Copy/paste foto ke folder ini (`public/assets/team/`)
4. Refresh browser untuk melihat hasilnya
